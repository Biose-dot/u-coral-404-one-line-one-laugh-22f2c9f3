# One Line, One Laugh

One short line: you ask the void for a sign, and the void answers like every app does — a push notification, and a paywall on silence itself.

> I asked the void for a sign; it sent me a push notification saying my free trial of silence ends tomorrow.

`main.py` copies the committed line in `assets/entry.txt` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
